# ბიოლოგიური ფსიქოლოგია — სავარჯიშო ტესტები

თსუ-ს კურსის „ბიოლოგიური ფსიქოლოგია“ შუალედური და ფინალური გამოცდების წინა წლების საკითხები, ინტერაქტიული ტესტის სახით. ძრავა აღებულია ეროვნული გამოცდების სავარჯიშო აპიდან (`exam_project`), მონაცემები და ნავიგაცია ახალია.

- **3 გამოცდა, 16 ბუკლეტი:**
  - შუალედური 1: ვარიანტები I–IV და დამატებითი კითხვები;
  - შუალედური 2: ტესტები, ვარიანტები II–III, დამატებითი და ღია კითხვები;
  - ფინალური: ტესტები I–III, მოკლე კითხვები, ღია კითხვები I–II.
- **423 კითხვა ბუკლეტებში, 243 უნიკალური**: 108 ტესტური და 135 ღია. ერთი კითხვა რამდენიმე ბუკლეტში შეიძლება მეორდებოდეს.
- ტესტური კითხვები ავტომატურად მოწმდება. ღია კითხვებზე დასრულების შემდეგ სამოდელო პასუხი ჩანს და სტუდენტი თავად მონიშნავს ✓ ან ✗.
- შედეგების ეკრანზე თითოეულ კითხვას აქვს ახსნა (📖) იოსელიანის „ადამიანის ფიზიოლოგიის“ (2001) გვერდებით. ჩანაწერი „გვ. 71–72 (ახ. 101–103)“ ნიშნავს: ორიგინალის გვ. 71–72, აწყობილი გამოცემის გვ. 101–103.

## კითხვის შეცვლა ან დამატება

1. შეცვალეთ `tools/bank_*.txt`:

   ```
   @m04
   Q: ტესტური კითხვის ტექსტი
   - არასწორი ვარიანტი
   * სწორი ვარიანტი
   E: ახსნა, გვერდით {p:71-72}
   N: გასაღების შესწორების შენიშვნა (არასავალდებულო)

   @o01
   O: ღია კითხვის ტექსტი
   A: სამოდელო პასუხი {p:50}
   ```

   რამდენიმე `*` ნიშნავს, რომ რომელიმე მათგანის არჩევა სწორად ჩაითვლება.
2. ახალი კითხვის id ჩაწერეთ `tools/papers.txt`-ში საჭირო ბუკლეტის ქვეშ.
3. ააწყვეთ:

   ```bash
   python -I tools/build_data.py
   ```

   სკრიპტი ჩერდება, თუ კითხვა არასწორადაა ჩაწერილი: არ აქვს სწორი ვარიანტი, ვარიანტი მეორდება, აკლია პასუხი ან id უცნობია. ბოლოს ბეჭდავს ბუკლეტების სიას და შესწორებებს.
4. ბრაუზერის ქეშისთვის `index.html`-ში `data.js?v=N` ნომერი გაზარდეთ.
